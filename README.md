# trilha-de-aprendizado-desenvolvedor-full-web-mobile
Trilha de estudos estruturado para desenvolvedor iniciante Full Stack Web e Mobile.

# Contexto
- Nem sempre o iniciante numa carreira, principalmente em Tecnologia sabe realemnte poor onde iniciar, considerando que há muito conteúdo para conhecer. Assim criei esse repositório como um guia iniciante a seguir ao longo de 180 dias (24 semanas) com 12 horas semanais de estudo, a fim de se tornar um desenvolvedor full stack web e mobile iniciante, entregando fundamentos, prática, projetos de portfólio e preparação para entrevistas. O conteúdo inclui roadmap detalhado, mapa de skills, projeto principal e indicação de trilhas complementares. O RoadMap apresenta a linguagem Python.

# Objetivo
- Fornecer um plano de estudos passo a passo para alcançar o primeiro emprego ou estágio como Desenvolvedor Full Stack.
- Organização de cursos, atividades práticas e metas semanais para facilitar acompanhamento e execução.
- Entregar um projeto de portfólio completo (Web + Mobile + Backend) pronto para desenvolvimento e publicação no GitHub.

# Mapa de skills
## Visão do dia a dia
O trabalho do dia a dia de um(a) Desenvolvedor(a) Full Stack envolve:
- Criar interfaces web e mobile responsivas.
- Desenvolver APIs e serviços de backend.
- Integrar banco de dados com aplicações.
- Testar e corrigir bugs em diferentes camadas da aplicação.
- Colaborar com equipes de design, produto e QA. Isso requer determinados Core Skills

## Core skills (essenciais)
- Lógica de programação e algoritmos
- HTML, CSS, JavaScript
- Python (Flask ou Django) para quem prefere a linguagem Python
- React (web) e React Native (mobile)

## Ferramentas e tecnologias
- Git / GitHub
- Banco de dados SQL (PostgreSQL / MySQL)
- Docker (básico para deploy)

## Nice-to-have (complementares)
- Fundamentos de inteligência artificial aplicada a projetos simples (essenciais para os dias atuais e futuros)
- Noções de redes e protocolos web

# Roadmap de 180 dias
## Adaptado para: 12 horas por semana
### Mês 1–2/Fundamentos

```
Semana 1–2
- Tópicos: Python básico — sintaxe, variáveis, estruturas, funções.
- Atividades: exercícios práticos e pequenos scripts.
- Meta: 5 scripts resolvendo problemas básicos.

Semana 3–4
- Tópicos: HTML e CSS — layout responsivo; Git/GitHub básico.
- Atividades: criar páginas estáticas e publicar no GitHub Pages.
- Meta: 2 páginas responsivas publicadas.

Semana 5–6
- Tópicos: JavaScript básico — DOM, eventos, funções.
- Atividades: projetos pequenos (calculadora, to-do local).
- Meta: 2 mini-apps em JavaScript.

Semana 7–8
- Tópicos: SQL básico e modelagem de dados.
- Atividades: criar esquema de banco e consultas CRUD.
- Meta: scripts SQL com operações CRUD.
```

### Mês 3–4/Prática
```
Semana 9–10
- Tópicos: React fundamentos — componentes, props, state.
- Atividades: tutoriais e exercícios guiados.
- Meta: componente de lista interativa.

Semana 11–12
- Tópicos: Projeto React — to-do com persistência local.
- Atividades: construir app, testes unitários básicos.
- Meta: app React funcional no GitHub.

Semana 13–14
- Tópicos: Backend em Flask ou Django — rotas, modelos, CRUD.
- Atividades: criar API REST simples.
- Meta: API com endpoints CRUD documentados.

Semana 15–16
- Tópicos: Integração frontend + backend; deploy simples (Heroku, Vercel ou Render).
- Atividades: conectar React à API, testes de integração.
- Meta: aplicação fullstack deployada e acessível publicamente.
```

### Mês 5–6/Portfólio e preparação
```
Semana 17–18
Tópicos: React Native básico — componentes, navegação, UI.
Atividades: criar app mobile simples (lista de tarefas).
Meta: app mobile com interface básica.

Semana 19–20
- Tópicos: Autenticação e persistência — JWT, sessions; testes.
- Atividades: implementar login no backend e no mobile; testes de fluxo.
- Meta: login funcional e sincronização entre web e mobile.

Semana 21–22
- Tópicos: Construção do Projeto 1 integrando web, mobile e backend.
- Atividades: finalizar features, testes end-to-end, correções.
- Meta: projeto completo no GitHub com código e documentação.

Semana 23–24
- Tópicos: Documentação, README, portfólio e preparação para entrevistas.
- Atividades: gravar vídeo demo, preparar respostas para entrevistas técnicas e comportamentais, simulações.
- Meta: portfólio publicado e 5 simulações de entrevistas realizadas.
```

# Projeto_de_portfólio
## Projeto: Plataforma de Lista de Tarefas Web + Mobile com Autenticação

### O que fazer  
```
Criar uma aplicação que permita cadastro/login de usuários, criação e gerenciamento de tarefas, acessível via web e mobile.
```

### Entregáveis
```
- Frontend web em React.
- Mobile em React Native.
- Backend em Python (API REST) com banco de dados relacional.
```

### Critérios_de_aceitação
```
- CRUD completo com autenticação de usuários.
- Interface responsiva e amigável.
- Deploy funcional (web e backend) e código documentado no GitHub.
```

### Dica prática
```
Comece pelo backend (modelos, endpoints e autenticação), depois desenvolva o frontend web e finalize com a versão mobile. Versione tudo no GitHub e escreva um README claro para cada serviço.
```
